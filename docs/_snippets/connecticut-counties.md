!!! note "Connecticut"
    This source keys Connecticut by the eight counties it had before 2022, not
    by the nine planning regions that replaced them as county equivalents. Name
    a county, such as `--location "Hartford County, CT"` or `"09003"`. A
    planning region such as `"Capitol Planning Region, CT"` is refused with the
    counties it overlaps, since the source has no rows under its code. A code
    given as a parameter is sent as given. See
    [Connecticut](/reference/places.md#connecticut).
