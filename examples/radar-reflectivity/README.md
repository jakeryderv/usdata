# NEXRAD reflectivity

Available since v0.8.

Open the [executed notebook](example.ipynb) to fetch one KTLX volume, inspect
sweep fields and units, plot reflectivity by azimuth and slant range, and check
provenance/cache reuse. The download is about 10 MB; decoding uses several
hundred MB of memory.

Run `just notebooks` from the repository root. See the [examples guide](../README.md)
for fresh-kernel execution and output refresh instructions.
