A partial GRIB2 fetch now records the index selector each message was fetched for. Provenance gains `selectors`, aligned with `ranges`; every entry of `dataset.attrs["usdata"]["messages"]` gains `selector`; `usdata inspect` prints a `selector` column for a partial file; and `Grib2Summary.variable_for(selector)` returns the variable name the reader's naming rule gives that message, so `CAPE:surface` can be looked up as `cape_entireAtmosphere_0` instead of guessed.
