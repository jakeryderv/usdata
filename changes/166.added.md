`usdata inspect <cache path | dataset id and asset id>` and `FetchedAsset.inspect()` summarize what a fetched file holds: provenance and size for any file, CSV columns and a capped row count with no extra installed, NetCDF4 variables with dims and units, and GRIB2 messages as a table of `shortName`, `typeOfLevel`, `level`, and step. A missing extra is reported as a note instead of an error, `--json` emits the summary, and the new `usdata.readers.inventory(path)` gives the GRIB2 message list that the reader's "pass select" error has been the only source of until now.
