Public functions that take a filesystem path now accept a `str` as well as a `Path`, coercing once on entry, so the path `usdata inspect` prints can be pasted straight into `inspect_path` instead of raising `AttributeError`. This covers `inspect_path`, `readers.inventory`, `fetch`, `fetch_asset`, `cite_lockfile`, `pull`, `resolve`, `restore`, `plan`, `verify`, `Manifest.load`, `Lockfile.load`, `Lockfile.save`, and `Registry.from_yaml`.
