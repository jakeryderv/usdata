The adapter contract is public. `usdata.providers` now exports `Provider`, `HttpProvider` (the HTTP client lifecycle previously named `providers._http._HttpProvider`), `QueryError`, `NotImplementedProvider`, `load_adapter`, and the parameter coercions, and the new `usdata.testing` module runs the contract checks -- listing, refusals before transport, exact bytes to an exact path, client ownership, and the entry's declared capabilities -- against any adapter, including one maintained outside this repository. `usdata.providers._http` is gone; import `HttpProvider` from `usdata.providers`.
