GRIB2 variable names now follow only from the messages a `select` matched: every variable is named `shortName_typeOfLevel_level` when the selection spans more than one type of level or more than one level within a type, and every variable keeps its bare `shortName` when they all share one, so the same select always returns the same names instead of suffixing only the short names that happened to repeat. `dataset.attrs["usdata"]["messages"]` maps each variable name to its message's index, `shortName`, `typeOfLevel`, `level`, and `step`. A select that spans levels whose short names did not repeat now returns a suffixed name where it previously returned a bare one.
