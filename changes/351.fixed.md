Every datetime in the public models (`TimeRange`, `Provenance`, `TemporalSelection`, `Lockfile`, `CacheEntry`, and inspection results) is now stored as aware UTC, reading a naive value as UTC as the rest of usdata does. Models built directly in Python no longer raise `TypeError`: a `TimeRange` mixing naive and aware bounds, a registry search with a naive window, a sidecar with a naive `retrieved_at` during `usdata cache prune --older-than`, and adapters listing a mix of naive and aware start times now all behave as UTC.
