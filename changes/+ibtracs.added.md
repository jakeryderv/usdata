`noaa:ibtracs` fetches one whole IBTrACS file, the global tropical cyclone best-track archive NCEI merges from every agency: a required subset names the complete record, the active storms, the last three seasons, everything since 1980, or one of seven basins, a format picks the CSV list or the NetCDF file, and the newest product version wins unless one is pinned. The CSV opens with the units-row reader, which reads the file's single-space missing cells as missing and keeps the North Atlantic basin code `NA` as text. A manifest example ranks the strongest recent storms with provisional tracks labelled. Directory listings now also yield the modified stamp, which IBTrACS assets carry as their end bound.
